BDI 讨论怎样保存目标和执行计划。DQN 保存与环境的交互记录，用这些记录训练网络，让网络估计各个动作的价值。

**Human-level control through deep reinforcement learning** 是 Mnih 等人发表于 Nature 2015 年的论文。它用深度 Q 网络读取游戏画面，估计各个动作的价值，并根据游戏反馈训练网络。下面分别看交互时发生什么，以及保存下来的经验怎样改变网络参数。

## 状态、动作和奖励怎样连起来

用 Pong 这种打乒乓球的游戏举例，动作简化为“向上”“向下”“不动”。实际合法动作集合由游戏环境提供。

程序读取球和挡板的画面，选择向下移动。游戏执行动作，返回新画面和奖励，程序据此选择下一步动作。

```text
观察当前情况 s
    → 选择动作 a
    → 环境执行动作
    → 得到奖励 r 和下一状态 s′
    → 继续选择动作
```

状态包含决策所需的信息，动作是 agent 交给环境的操作，奖励由环境返回。具体任务决定三者的含义。论文在 Atari 中使用游戏分数的变化作为奖励。

Pong 赢得一分时可以给正奖励，丢掉一分时可以给负奖励。大部分普通移动没有立即得分，奖励为零。论文训练时把正奖励裁成 +1、负奖励裁成 −1，零保持为零，让不同游戏使用相同的奖励尺度。

其他游戏也按实际分数变化计算奖励。

## 用连续画面表示状态

球处在相同位置时，可能向上运动，也可能向下运动。单帧画面不一定能区分这两种情况。

论文用最近 4 帧画面，叠成 84 × 84 × 4 的网络输入。预处理取相邻帧的逐像素最大值，以减轻闪烁，随后提取亮度通道并缩放到 84 × 84。

实现里的“状态”由近期画面组成，网络从连续帧的变化中学习运动信息。

## Q 网络输出的是动作价值

论文用卷积网络读取画面，输出每个合法动作的 Q 值。例如，在一个教学状态下取下面这些数值：

| 动作 | 估计的 Q 值 |
| --- | ---: |
| 向上 | 1.2 |
| 向下 | 2.0 |
| 不动 | 0.5 |

表中的数值只用于演示计算。

表中的 2.0 是动作价值估计。Q(s, a) 估计在状态 s 执行动作 a 并继续行动后，能够得到的折扣累计奖励，包括之后可能得到的奖励。网络通过训练，让估计逐渐接近最优动作价值。

按当前估计，程序会选择“向下”。训练还需要探索其他动作，论文采用 ε-greedy：多数时候选 Q 值最高的动作，小部分时候随机选择。

策略指选择动作的规则。DQN 学习 Q 值，用这些估计决定动作。

卷积层提取画面特征，全连接层据此估计动作价值。一次前向计算就能得到当前状态下所有合法动作的 Q 值。

## 即时奖励为零时怎样更新 Q 值

一次动作可能让 agent 到达更容易得分的位置，训练目标会用下一状态的价值更新当前动作的估计。对一条尚未结束的经验，原论文的目标可以写成：

<div class="paper-equation" role="math" aria-label="训练目标等于即时奖励加上折扣因子乘以下一状态的最大目标网络动作价值">y = r + γ max<sub>a′</sub> Q<sub>target</sub>(s′, a′)</div>

其中 r 是本次实际奖励，γ 是折扣因子，s′ 是动作后的状态。论文设置 γ = 0.99。

沿用前面的数值：当前网络给“向下”的 Q 值为 2.0，这次移动没有立即得分，r = 0。到达新状态后，目标网络给最好动作的估计是 4.0，训练目标如下：

```text
训练目标 y = 0 + 0.99 × 4.0 = 3.96
当前预测 Q(s, 向下) = 2.0
```

当前预测低于目标，训练通过损失和梯度修改网络参数，使这个状态下“向下”的估计向 3.96 调整。共享参数还可能改变其他状态和动作的预测。

后续状态的价值由此影响前面动作的估计。一个没有立即得分的动作，如果让 agent 到达了更容易得分的位置，也可以学到较高的价值。

经验已经结束时，没有后续奖励需要估计，目标改为 y = r。

## 经验回放与目标网络

训练会保存交互记录，每条记录包含：

```text
(当前状态, 执行动作, 实际奖励, 下一状态, 是否结束)
```

论文的经验池最多保存约 100 万条近期经验，训练时随机抽取 32 条组成小批次。相邻画面通常很像，按最新画面连续更新会让训练数据高度相关。随机抽样减轻了这种相关性，也让旧经验能够重复使用。

当前 Q 网络一直更新。如果训练目标也由它即时计算，预测和目标就会同时变化。论文用另一份目标网络计算下一状态的价值。

论文复制一份网络作为目标网络，一段更新期间固定它的参数，用它计算下一状态的价值。每隔一定步数，当前 Q 网络的参数会同步到目标网络。两者结构相同，更新频率不同。

一次更新使用环境返回的即时奖励，以及暂时固定的目标网络对下一状态的估计。

## 完整训练流程

```text
开始一局游戏，准备近期画面的状态表示
重复：
    当前 Q 网络估计各动作的价值
    用 ε-greedy 选择动作
    环境执行动作，返回奖励与新画面
    把这次交互存进经验池
    从经验池随机取一批经验
    用目标网络计算训练目标
    更新当前 Q 网络
    定期同步目标网络
    若游戏结束，开始新一局
```

执行动作会改变环境状态，使用经验训练则会改变网络参数。上面的流程同时包含这两种变化。

## 49 个游戏的实验结果

论文在 49 个 Atari 游戏中使用相同算法、网络架构和超参数，每个游戏分别训练一个网络。

原文报告，DQN 在 43 个游戏上超过参与比较的先前强化学习方法，在 29 个游戏上达到超过人类测试者分数 75% 的水平。同一套方法能够用于多种游戏任务，标题中的 human-level 对应的是这些实验结果。

## 对照 Agent 的工具调用

DQN 将观察、动作和环境反馈放进同一个循环，用保存的经验训练网络。对照 LLM Agent 的工具调用，可以检查它读取了什么信息、执行了什么操作，以及怎样根据工具结果决定下一步。
