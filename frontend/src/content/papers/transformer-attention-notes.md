Transformer 的编码器读取源文本，解码器结合源文本和目标前文预测下一词。

目标侧输入右移一位，让每个位置的输出预测接下来的词。掩码遮住后面的位置，自注意力读取当前位置及之前的输入，交叉注意力读取编码器输出。下面按结构图讲解 QKV 和这些计算步骤。

以下按 Vaswani 等人 2017 年的 **Attention Is All You Need** 讲解编码器—解码器 Transformer。例子把“我、喜欢、猫”当作三个 token。配图根据原文重绘，数值用于演示计算。

## 编码器和解码器分别读什么

原论文主要做机器翻译。结构图左侧是编码器，读取完整输入；右侧是解码器，逐步生成目标文本。例如，输入英文 “I like cats”，输出中文“我喜欢猫”。

源文本已经给定，编码器可以同时读取各个位置。解码器生成当前词时，后面的目标词还未知，它能读取已生成的目标前文和编码器输出。

## 词嵌入与第一层输入

用“我”的词嵌入举例。为了演示，把它写成四维向量：

```text
E我 = [0.2, 0.1, -0.3, 0.4]
```

四维就是四个数值分量。第 0 维是 0.2，第 1 维是 0.1，以此类推。原论文的基础模型实际使用 512 维。

模型参数固定时，同一个 token 查到的初始词嵌入相同。“我”放在句子开头或结尾，查到的这个向量都一样。

第 0 维、第 1 维都是数值分量。模型通过训练调整这些数值，通常用多个分量共同表示信息。

进入第一层注意力前，模型会加入位置编码。把嵌入层输出的向量记作 E，输入就是 X = E + PE。原论文还对嵌入查表结果乘以 √d_model，这里将这一步包含在 E 中。

第一层用这些输入向量计算注意力，将其他位置的信息加到当前表示中。后面的层读取上一层输出，继续计算。

## Q、K、V 从哪里来

看到“Q：我 喜欢 猫；K：我 喜欢 猫”，容易把 Q 理解成查询上一个词，用来预测“喜欢”的下一个词。Q 可以与多个位置的 K 匹配，可查询的范围由当前层的连接方式决定。

对每一个输入位置，模型把当前表示分别乘上三个训练得到的矩阵，生成 Q、K、V：

<div class="paper-equation" role="math" aria-label="Q等于X乘WQ，K等于X乘WK，V等于X乘WV">Q = XW<sub>Q</sub>　 K = XW<sub>K</sub>　 V = XW<sub>V</sub></div>

自注意力中的三者来自同一组 X。由于投影矩阵不同，得到的向量通常也不同。每个位置各有一个 q、一个 k、一个 v，把各位置的向量按行排列，就得到 Q、K、V 矩阵。

Q、K、V 的分工可以按下面的表格理解。

| 向量 | 可以怎样理解 | 实际参与的计算 |
| --- | --- | --- |
| Q | 这个位置需要匹配什么信息 | 与允许访问的各个 K 打分 |
| K | 这个位置有哪些匹配特征 | 与 Q 计算匹配分数 |
| V | 从这个位置取出哪些数值 | 用注意力权重加权求和 |

“喜欢”位置的 Q 可以与多个位置的 K 计算分数。编码器允许读取完整输入；解码器的掩码自注意力允许读取当前位置及之前的输入。掩码会排除不允许访问的连接。

Q 负责匹配信息，预测下一词还需要后面的网络。注意力输出经过其他层和词表投影，最终得到下一 token 的概率。

## 缩放点积注意力的计算

原论文的缩放点积注意力写成：

<div class="paper-equation" role="math" aria-label="注意力等于Q乘K转置的分数除以根号dk，经过softmax后再乘V">Attention(Q, K, V) = softmax(QK<sup>T</sup> / √d<sub>k</sub>) V</div>

使用掩码时，模型在 softmax 前把不允许访问的分数设为负无穷，对应的权重就变成零。

把“喜欢”位置的一次查询展开。假设 q = [0, 1]，三个位置的 k 分别是 [1, 0]、[0, 1]、[1, 1]，点积得分就是 [0, 1, 1]。这里 d_k = 2，缩放后约为 [0, 0.707, 0.707]。

不使用掩码时，softmax 算出的权重约为 [0.198, 0.401, 0.401]。三个 v 分别取 [1, 0]、[0, 2]、[1, 1]，加权求和得到：

```text
0.198 × [1, 0]
+ 0.401 × [0, 2]
+ 0.401 × [1, 1]
≈ [0.599, 1.203]
```

把这个结果当成已经输出“猫”，就跳过了后续网络。注意力算出的是一个新的表示向量，下一词的概率还需要继续计算。下面可以切换查询位置，或勾选掩码，观察权重和输出怎样变化。Q、K、V 使用固定的教学数值。

<!-- demo:attention -->

Scale 把点积除以 √d_k。维度增大时，点积可能变大，softmax 容易把权重集中在少数位置上；缩放用于缓解这种情况。

## W_K 在训练中更新

K 怎样变化，需要分别看训练和前向计算。Wk 在训练时更新。训练根据最终任务的损失更新 W_Q、W_K、W_V，输入乘上这些矩阵后，Q、K 用于计算匹配分数，V 用于加权求和。

一次前向计算中，X 和 W_K 已经确定，K 就是 XW_K。换一个 Q，匹配分数和注意力权重会变化，同一层的 K 保持不变。

V 也由输入乘投影矩阵得到。可以把 K 类比成“匹配线索”，把 V 类比成“汇总内容”；V 保存的是投影后的数值，和原文不同。

各头的投影矩阵由训练更新，各头读取的信息也由这些计算决定。

## 编码器怎样读取其他位置

输入端的多头注意力与 CNN 都从输入中计算特征。编码器读取其他位置的信息，更新当前词的向量。例如，“小明喜欢猫，小红喜欢狗”这句话需要表达名字、动作和对象之间的关系。

注意力根据当前输入计算权重。某个位置的 Q 与各个 K 计算分数，权重决定怎样汇总 V。CNN 用卷积核读取局部输入并计算特征，更深的卷积层能读取更大的范围。这是两者在计算上的区别。

原论文的编码器自注意力允许每个输入位置读取其他输入位置，这就是“全局连接范围”的含义。

## 掩码自注意力怎样读取目标前文

只把后面的词遮住，还没有计算前面的词怎样影响当前位置。掩码排除不允许出现的连接，自注意力把可访问的信息汇总到当前位置。

比较下面两段已经生成的前文：

```text
小明 喜欢 → 下一词可能要描述小明喜欢的对象
小红 喜欢 → 下一词可能要描述小红喜欢的对象
```

两段前文都以“喜欢”结束，预测下一个词时还需要前面的名字。解码器把这段前文的信息汇总到当前位置，用这个表示查询源文本，并继续生成。

掩码自注意力读取这些前文，用各位置的 V 加权求和。它通常也允许读取当前位置自身：这里放的是已知的输入 token，预测目标则是接下来的 token。目标侧右移一位，就让当前输入对应下一词。

## 交叉注意力的 Q 来自解码器

“输入作为 Q、K，输出作为 V”容易把交叉注意力的来源配反。要继续生成目标文本的是解码器，它用本层掩码自注意力和 Add & Norm 的输出 S 计算 Q，查询源文本。编码器最终输出 H 分别乘投影矩阵，计算 K、V：

<div class="paper-equation" role="math" aria-label="交叉注意力的Q来自解码器S，K与V来自编码器H">Q = SW<sub>Q</sub>　 K = HW<sub>K</sub>　 V = HW<sub>V</sub></div>

在翻译例子里，解码器已生成“我喜欢”，需要从源文本 “I like cats” 中找到接下来生成所需的信息。当前位置的表示包含目标前文，交叉注意力用它查询编码器输出。

结构图右侧送入交叉注意力的是中间表示。最终预测出的词位于顶部：后续网络继续计算，词表线性层和 softmax 给出 token 概率。

三块注意力的输入来源如下：

| 注意力模块 | Q 来自哪里 | K、V 来自哪里 | 可以访问哪里 |
| --- | --- | --- | --- |
| 编码器自注意力 | 当前编码器层输入 | 同一组层输入 | 全部有效源文本位置 |
| 解码器掩码自注意力 | 当前解码器层输入 | 同一组层输入 | 当前及之前的目标输入位置 |
| 编码器—解码器交叉注意力 | 本层解码器的中间表示 | 编码器最终输出 | 全部有效源文本位置 |

表中的“有效位置”排除了 padding。Q 能使用哪些信息，要看输入来自哪里，以及当前模块允许连接哪些位置。

## 右移一位：对齐输入与目标

把结构图底部的 Outputs (shifted right) 当成下一词候选，就把输入认成了预测结果。这里的“输出”指目标文本，右移后的文本作为解码器输入，告诉模型已经知道哪些目标词。

假设完整目标是“我 喜欢 猫”。训练时，输入和目标按下表排列，开始与结束标记用于说明对齐关系：

| 位置 | 解码器输入 | 这一位置要预测的目标 |
| --- | --- | --- |
| 0 | 开始标记 | 我 |
| 1 | 我 | 喜欢 |
| 2 | 喜欢 | 猫 |
| 3 | 猫 | 结束标记 |

输入相对目标右移一位。位置 2 输入“喜欢”，输出用于预测“猫”。掩码允许它读取输入位置 0、1、2，即“开始标记、我、喜欢”，遮住位置 3 的输入“猫”。

训练时已知整句正确目标，可以一次准备全部输入与标签。这种使用正确前文作为输入的方式通常叫 teacher forcing。推理时，后面的词尚未生成，模型只能使用已有的生成结果。

“指针指向待预测的上一个词”描述的是输入与目标错开一位。掩码按位置规则遮住后面的输入，预测目标由训练数据指定。

### 同一个位置输入答案会怎样

同一个位置输入“猫”并预测“猫”，答案已经在自身输入里。“猫”可以进入 Q，也可以通过残差连接向后传。

注意力遮住自身的 K、V 时，Q 和残差连接仍然保留自身输入。

下一词任务应当给出截至“喜欢”的前文，让模型预测“猫”。标准编码器—解码器训练通过右移完成这种对齐。

### 在损失里移动标签

代码也可以移动标签：第 i 个位置的输出，与原序列第 i+1 个 token 的标签比较。有些预测下一 token 的语言模型就在计算损失时完成这一步。

移动输入或移动标签，都让“已知前文”对应“下一 token”。掩码负责限制能读取哪些输入。

解码器自注意力的 Q、K、V，都从同一组右移后的目标侧输入计算。交叉注意力的 K、V 来自源文本编码器。

## 训练时按矩阵并行计算

同一层把所有位置放在矩阵里计算。QKᵀ 算出位置之间的分数矩阵，掩码遮住后面的位置，softmax 与加权求和也按矩阵计算。

在上面的训练例子里，位置 0 预测“我”，位置 1 预测“喜欢”，位置 2 预测“猫”，位置 3 预测结束。正确输入已经准备好，同一层可以并行计算所有位置，掩码防止前面位置读取后面输入。

生成时，下一步输入依赖刚生成的 token，通常仍要逐步生成。层与层之间也有依赖：后一层使用前一层的输出。并行训练说的是同一层中各位置的矩阵计算。

## 位置编码怎样改变输入

在四维例子里交换“我”和“猫”，可以观察词序怎样影响输入。不加位置编码时，“我”的 embedding 不变；加入后，送进注意力的向量随位置改变。

这里加入的是当前位置的信息。原论文用正弦位置编码表示绝对位置，公式本身也方便模型学习相对位置关系。

```text
“我”在位置 0：X0 = E我 + PE(0)
“我”在位置 2：X2 = E我 + PE(2)
```

变化发生在相加后的 X，E我 保持相同。“我在位置 0”描述绝对位置，“猫在我后面，相隔两个位置”描述相对关系。

<!-- demo:position -->

例子中的 E 使用教学数值，PE 按原论文公式在 d = 4 时计算。表里展示的是第一层 QKV 投影前的输入。

### 没有位置特征时怎样计算

“我 喜欢 猫”和“猫 喜欢 我”使用相同的词，含义却不同。普通无掩码自注意力如果没有位置特征，输入换序时，输出也按同样的排列换序。矩阵行号本身没有向模型提供“这是第几位”的数值特征。

位置编码把序列位置加入每个词的输入，词内容和位置一起进入后面的计算。使用掩码时，各位置能读取的输入范围也不同。原论文给编码器和解码器都加入了位置编码。

### 计算位置向量

位置记作 p，向量维度记作 d。每对相邻维度使用同一频率的 sin 和 cos：

<div class="paper-equation" role="math" aria-label="位置p的第2i维是sin括号p除以10000的2i除以d次方">PE(p, 2i) = sin(p / 10000<sup>2i/d</sup>)</div>

<div class="paper-equation" role="math" aria-label="位置p的第2i加1维是cos括号p除以10000的2i除以d次方">PE(p, 2i + 1) = cos(p / 10000<sup>2i/d</sup>)</div>

p 表示 token 在序列中的位置，从 0 开始。i 对应一对维度：i = 0 指第 0、1 维，i = 1 指第 2、3 维。p 在索引词的位置，i 在索引位置向量中的维度对。

“第 i 维表示什么”要看正在讨论哪种向量。词嵌入中的分量由训练学得，位置编码中的分量则按公式计算，取某个频率的正弦或余弦值。

四维演示对应下面的公式：

| 维度 | 位置 p 对应的值 |
| --- | --- |
| 第 0 维 | sin(p) |
| 第 1 维 | cos(p) |
| 第 2 维 | sin(p / 100) |
| 第 3 维 | cos(p / 100) |

各分量使用不同频率，随位置变化的速度也不同，组合起来表示位置。位置 0 的向量是 [0, 1, 0, 1]，因为 cos(0) = 1。位置 0 的向量有非零分量。

公式中的 10000 用于安排频率尺度。

### 正弦结构与向量相加

对于固定的位置偏移 k，每对 sin、cos 在 p+k 处的值，都能由 p 处的值通过固定线性变换得到。作者据此提出，这种形式可能方便模型学习相对位置与注意力的关系。

计算 QK 分数时，词内容、投影矩阵和位置信息都会进入计算。

位置编码和词向量的维度相同，相加后保持原来的维度，可以直接送入网络。后续层读取这个相加后的向量。

固定公式也能计算训练中未出现过的位置。论文认为这可能方便模型读取更长的序列。

原论文也比较了可学习的位置嵌入，结果与正弦编码接近。

## Add & Norm、前馈层和词表输出

Feed Forward 和 Add & Norm 分别计算前馈输出与归一化结果。

原论文在每个子层外加入残差连接和归一化，写作 LayerNorm(x + Sublayer(x))。Add 将子层输入与输出相加，Norm 对结果做层归一化。

Feed Forward 是逐位置的前馈网络，各位置使用相同的两层计算，中间经过 ReLU。它读取已经汇总的特征，位置之间的匹配由注意力完成。基础模型将 512 维映射到 2048 维，然后映射回 512 维。

解码器顶部的 Linear 输出词表大小的向量，Softmax 算出各 token 的概率，用于训练或选择下一 token。注意力内部的 softmax 则计算各个可访问位置的权重。两处 softmax 的计算对象不同。

## “喜欢”这个位置怎样预测“猫”

回到翻译例子：源文本是 “I like cats”，目标文本是“我 喜欢 猫”。训练中的“喜欢”输入位置经过这些步骤：

1. 源文本经过嵌入、位置编码和编码器，得到每个源位置的表示 H。
2. 目标侧输入已经右移，当前这个位置放的是“喜欢”，它的训练目标是“猫”。
3. 掩码自注意力读取“开始标记、我、喜欢”，将前文信息加权求和，计算当前位置的表示。
4. 交叉注意力用这个解码器表示计算 Q，用 H 分别计算 K、V，加权求和，读取源文本中有用的信息。
5. 表示继续经过后面的模块，最终投影到词表，得到下一 token 的概率。
6. 训练拿这些概率与正确目标“猫”计算损失，反向更新可学习参数；生成时则根据概率选 token，把选出的结果加入前文，继续下一步。

源文本里的 cats 属于给定输入，可以读取。掩码遮住的是目标侧后面位置的“猫”。
